# Showcase library

The books the site's app snapshot shows (`scripts/snapshot-app.mjs`), with their first-edition covers. Every cover was published in 1930 or earlier, so it is in the public domain in the United States, and each comes from a [Wikimedia Commons](https://commons.wikimedia.org) file marked public domain there, resized to 420 pixels tall. Only add covers with the same standing, and record their source below.

`books.json` lists the books. `reading` is a percentage read or `finished`.
