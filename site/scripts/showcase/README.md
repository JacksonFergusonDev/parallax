# Showcase library

The books the site's app snapshot shows (`scripts/snapshot-app.mjs`). The covers are from [Standard Ebooks](https://standardebooks.org), resized to 400 pixels tall. Standard Ebooks says the text and cover art of its ebooks are believed to be in the US public domain, and dedicates its own work, including the cover designs, to the public domain under [CC0](https://creativecommons.org/publicdomain/zero/1.0/). Only add books whose covers come with the same terms.

`books.json` lists them in library order. `reading` is a percentage read or `finished`.
